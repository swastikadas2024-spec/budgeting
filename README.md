# Budget Hero — Financial Literacy Simulator

This is a starter scaffold for a mobile-first, game-like financial literacy simulator built with:

- React + Vite
- TailwindCSS
- Framer Motion

Quick start:

```bash
npm install
npm run dev
```

What to explore next:

- Add more event variations and delayed consequences
- Improve art, sounds, and character personalities
- Add persistence (localStorage) and achievements
